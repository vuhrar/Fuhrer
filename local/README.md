# Führer Local

نسخة PWA محلية مجانية بالكامل. تحفظ القضايا والوقائع والطلبات وفهرس المستندات داخل متصفح الجهاز عبر IndexedDB، ولا تحتاج إلى FastAPI أو قاعدة بيانات أو حساب.

## الاستخدام

1. افتح رابط النسخة من Safari.
2. اضغط «فتح مساحة العمل».
3. أدخل عنوان القضية والطرف المقابل والملخص ثم احفظ.
4. أضف الوقائع والطلبات والمستندات.
5. صدّر نسخة Markdown أو HTML أو JSON.
6. صدّر نسخة احتياطية مشفرة بانتظام من تبويب «النسخ الاحتياطي».
7. في Safari اختر «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

## حدود مهمة

البيانات محلية على هذا الجهاز ولا توجد مزامنة بين الأجهزة. حذف بيانات Safari أو فقدان الهاتف قد يؤدي إلى فقدان البيانات؛ لذلك يجب استخدام النسخ الاحتياطي المشفر. هذه النسخة لا تستخدم نموذج ذكاء اصطناعي خارجي ولا تقدم رأيًا قانونيًا نهائيًا. يجب التحقق من المصادر ومراجعة محامٍ مرخص قبل أي إجراء رسمي.
