# Führer — المساعد القانوني الشخصي

تطبيق محلي لمستخدم واحد، يقدّم أدوات مساعدة في البحث القانوني والتحليل الأولي والحسابات والمستندات في نطاق الأنظمة السعودية. **مسار التشغيل الرسمي الوحيد هو Streamlit عبر `app.py`**. تم إبقاء الوحدات القديمة مثل CLI وFastAPI داخل المستودع لأغراض التوافق والتحويل التدريجي، لكنها ليست جزءًا من مسار التشغيل المدعوم.

> **تنبيه قانوني:** مخرجات التطبيق معلومات مساعدة ومسودات أولية، وليست استشارة قانونية نهائية ولا بديلاً عن مراجعة محامٍ مؤهل. يجب التحقق من النص النظامي والوقائع والإصدارات قبل اتخاذ أي إجراء.

## المزايا الحالية

يتيح التطبيق للمستخدم الفردي اختيار دور مهني من الأدوار المعتمدة، ثم استعمال الأدوات المناسبة له من واجهة واحدة: البحث في الأنظمة واللوائح، حساب الاستحقاقات، تقييم القضية والمخاطر، فحص المراسلات، استخراج البيانات من المستندات، التسوية، ومركز التقاضي.

الواجهة مهيأة لشاشة iPhone 13 تقريبًا بعرض 390px، وتستخدم تخطيطًا مركزيًا وأزرارًا كبيرة وحقول إدخال مناسبة للمس، ولا تعتمد على شريط جانبي أو تنقل متعدد الصفحات.

## التشغيل المحلي

### 1. إعداد البيئة

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

افتح `.env` وغيّر `APP_ACCESS_TOKEN` إلى رمز طويل وفريد. لا تضع ملف `.env` في Git ولا تشارك الرمز مع أي شخص.

### 2. تشغيل المسار الرسمي

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

بعد التشغيل، افتح من iPhone عنوان الجهاز المضيف على الشبكة المحلية:

```text
http://IP-ADDRESS-OF-HOST:8501
```

يجب أن يكون iPhone والجهاز الذي يشغل Python على شبكة Wi‑Fi خاصة واحدة. لا تفتح المنفذ على الإنترنت ولا تستخدم Port Forwarding. إذا احتجت وصولًا خارج المنزل، استخدم VPN خاصًا مثل Tailscale أو WireGuard بدل نشر المنفذ للعامة.

## نموذج إعداد `.env`

```dotenv
REQUIRE_ACCESS_TOKEN=true
APP_ACCESS_TOKEN=ضع_رمزًا_طويلًا_وفريدًا_هنا
STREAMLIT_SERVER_ADDRESS=0.0.0.0
STREAMLIT_SERVER_PORT=8501
PRESET_NAME=Führer Law Brain (Qwen 0.6B) 🧠
```

عند استخدام نموذج سحابي، أضف مفتاح المزود المطلوب فقط. يفضّل تشغيل النموذج المحلي عبر LM Studio لتقليل إرسال المستندات الحساسة إلى طرف خارجي. لا يوفّر التطبيق حاليًا حسابات متعددة أو دعوات أو مشاركة قضايا، وهو مصمم لجلسة مستخدم واحدة.

## حدود الخصوصية الحالية

رمز الوصول يضيف حاجزًا عمليًا على واجهة التطبيق، لكن التطبيق ليس نظام هوية متعدد المستخدمين. الحماية الأساسية تعتمد على إبقاء الجهاز والشبكة خاصة، واستخدام رمز قوي، وعدم نشر المنفذ. ملفات البيانات المحلية التي تنتجها الوحدات القديمة تُحفظ عادة تحت `~/fuhrer_data`، لذلك يجب تأمين حساب نظام التشغيل والنسخ الاحتياطية.

## بنية التشغيل

```text
app.py
  ├── بوابة رمز الوصول لمستخدم واحد
  ├── واجهة Streamlit المتجاوبة

  └── استدعاء أدوات الأعمال من tools.py
        ├── legal_tools_advanced.py
        ├── litigation_tools.py
        ├── analysis_engine.py
        ├── legal_database.py
        ├── file_processing.py
        └── ai_engine.py
```

## الاختبار قبل الاستخدام

```bash
python3 -m compileall -q *.py
python3 -m pytest -q
```

لا تعتمد على نتيجة الحاسبة أو التحليل دون مراجعة المادة القانونية ومصدرها وتاريخ نفاذها. كما أن OCR واستخراج النص من PDF قد يكونان جزئيين، ولذلك يجب مقارنة النص المستخرج بالوثيقة الأصلية.

## التشغيل السابق غير المدعوم

الملف `server.py` ومسار `fuhrer.py` موجودان في المستودع للانتقال التدريجي فقط. لا تستخدم `uvicorn server:app` كمسار التطبيق الرسمي؛ فهو لا يطبق تجربة المستخدم الموحدة ولا سياسة الوصول الفردي بالطريقة نفسها.
