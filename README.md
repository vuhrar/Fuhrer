# Führer — تطبيق ويب تقدمي قانوني خاص

تم تحويل المشروع إلى **FastAPI + HTML/PWA**. لا يعتمد المسار الرسمي على Streamlit، ولا يحتاج المستخدم إلى تثبيت تطبيق من App Store. يفتح المستخدم التطبيق من Safari على iPhone 13، ثم يختار **إضافة إلى الشاشة الرئيسية** ليعمل بواجهة قريبة من التطبيق.

> التطبيق مساعد قانوني أولي. مخرجاته ليست استشارة نهائية ولا بديلاً عن محامٍ مؤهل أو التحقق من النظام والوقائع والإصدار النافذ.

## ما تم توحيده

| المكوّن | المسار النهائي |
|---|---|
| نقطة الدخول | `server.py` عبر Uvicorn |
| الواجهة | `web/templates/index.html` |
| التصميم | `web/static/styles.css`، متجاوب مع iPhone 13 |
| منطق الواجهة | `web/static/app.js` |
| PWA | `manifest.json` و`sw.js` |
| الوصول | رمز واحد عبر `APP_ACCESS_TOKEN` |
| الحسابات | لا توجد حسابات متعددة أو مشاركة |
| API | `/api/analyze`، `/api/law-search`، `/api/calculate/eosb`، `/api/upload` |

## التشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

في `.env` ضع رمزًا طويلًا وفريدًا:

```dotenv
APP_ACCESS_TOKEN=غيّر_هذا_إلى_رمز_خاص_وطويل
PRESET_NAME=Führer Law Brain (Qwen 0.6B) 🧠
STREAMLIT_SERVER_ADDRESS=0.0.0.0
STREAMLIT_SERVER_PORT=8501
```

شغّل الخادم:

```bash
uvicorn server:app --host 0.0.0.0 --port 8000
```

من iPhone افتح:

```text
http://عنوان-الجهاز-المضيف:8000
```

ثم من قائمة Safari اختر **إضافة إلى الشاشة الرئيسية**. يجب أن يكون الهاتف والجهاز الذي يشغل الخادم على شبكة خاصة واحدة، وألا يتم فتح المنفذ للعامة أو استخدام Port Forwarding.

## النماذج ومفاتيح المزودين

للنموذج المحلي، شغّل نقطة LM Studio على الجهاز المضيف. وللنماذج السحابية، ضع المفتاح المناسب في `.env` مثل `OPENAI_API_KEY` أو `ANTHROPIC_API_KEY` أو `HF_API_KEY`. لا ترسل مفاتيح المزودين من المتصفح؛ الخادم يقرأها من البيئة. إذا كان المطلوب أن يعمل التطبيق من iPhone دون جهاز مضيف، فلابد من نشر هذا الخادم على خدمة استضافة خاصة؛ PWA وحدها لا تشغل Python داخل Safari.

## الخصوصية والحدود

الخادم يرفض الطلبات المحمية دون `X-App-Token`، ولا توجد واجهة تسجيل أو مشاركة. تم تحديد رفع الملفات بخمسة ملفات كحد أقصى و25MB لكل ملف. لا تضع `.env` أو مستندات القضايا داخل Git، واحذف الملفات الحساسة بعد انتهاء العمل. لا تستخدم HTTP على شبكة عامة؛ استخدم HTTPS عبر Reverse Proxy أو VPN خاص عند النشر خارج الشبكة المنزلية.

## ملفات Streamlit القديمة

تم إزالة Streamlit من التبعيات ومن مسار التشغيل الرسمي. قد تبقى بعض الوحدات القديمة داخل المستودع للتوافق التاريخي، لكنها لا تُستورد بواسطة `server.py` ولا تدخل في تشغيل PWA. المسار المدعوم حاليًا هو:

```text
Safari/PWA → FastAPI server.py → خدمات التحليل والبحث والحساب ومعالجة الملفات
```
